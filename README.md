# 🇴🇲 مُيسّر الاستثمار العُماني (Oman Invest Accessibility)

مشروع مشارك في تحدي **مجان للمبرمجين — UX/UI Accessibility**.
يهدف المشروع إلى مساعدة رواد الأعمال والمستثمرين في سلطنة عُمان على تحديد الموقع الأنسب لمشاريعهم (مثل الجبل الأخضر، صلالة، مطرح، الخوض السادسة، الموج مسقط، وصحار) عبر تجربة رقمية شاملة وميسّرة تتيح للجميع التفاعل مع البيانات والخرائط بسهولة تامة.

🔗 **رابط التجربة المباشرة (Live Demo):**
https://ilxa2m.github.io/Oman-invest-a11y/ 
---

## ⚙️ طريقة عمل المشروع (How It Works)

1. **تحديد معايير المشروع:** يختار المستخدم **نوع البزنس** (مقهى، نشاط سياحي، عطور وبخور، خدمات)، **الفئة المستهدفة** (السياح، العائلات، الشباب)، و**الأولوية الأهم** (الإقبال السياحي، الكثافة السكانية، أو الإيجار الاقتصادي بالريال العُماني OMR).
2. **محرك التقييم الذكي:** يقوم النظام بحساب نسبة التوافق لكل منطقة وترتيب المواقع الأنسب تلقائياً مع عرض مؤشرات بصرية واضحة لا تعتمد على اللون فقط.
3. **الخريطة التفاعلية وبيانات Wikipedia API:** عند النقر على أي موقع، تنتقل الخريطة تلقائياً إلى إحداثياته وتجلب نبذة جغرافية وسياحية موثقة ومباشرة من موسوعة ويكيبيديا العربية.
4. **أدوات إمكانية الوصول الشاملة (Accessibility Suite):** يمكن للمستخدم تفعيل القراءة الصوتية، تكبير النصوص، فلاتر عمى الألوان، أو أوضاع العرض المختلفة في أي لحظة.

---

## ♿ ميزات إمكانية الوصول المطبقة (Accessibility Features)

* **🔊 القراءة الصوتية (Voiceover):** قراءة تفاصيل أي موقع أو ملخص الصفحة أو أي نص محدد باللغة العربية باستخدام `Web Speech API`.
* **🔠 مرونة النصوص (Responsive Text):** تكبير وتصغير الخطوط وتعديل تباعد الأسطر دون كسر تخطيط البطاقات أو الخريطة.
* **🎨 دعم عمى الألوان (Color Blindness):** فلاتر SVG حقيقية لأنواع عمى الألوان (*Protanopia, Deuteranopia, Tritanopia*) مع الاعتماد على الأيقونات والرموز بجانب الألوان.
* **👁️ أوضاع عرض متعددة (Multiple View Modes):** الوضع الليلي (Dark Mode)، وضع التباين العالي (High Contrast)، ووضع القراءة الهادئة لإخفاء الخريطة والعناصر المشتتة.
* **⌨️ دعم قارئات الشاشة والاختصارات (Screen Readers & Shortcuts):** كود HTML دلالي مع وسوم `ARIA` واختصارات لوحة مفاتيح سريعة:
  * `Alt + A`: فتح/إغلاق لوحة أدوات الوصول.
  * `Alt + V`: قراءة تفاصيل المنطقة المختارة صوتياً.
  * `Alt + +` / `Alt + -`: تكبير وتصغير حجم الخط.
  * `Alt + R`: إعادة ضبط جميع الإعدادات.
* **🧩 كود قابل لإعادة الاستخدام + إضافة متصفح (Reusable Code & Browser Extension):** أداة الوصول مبنية في ملف مستقل تماماً (`a11y-toolkit.js`) ويمكن تثبيتها كإضافة متصفح Chrome/Edge عبر ملف `manifest.json`.

## 🚀 خطوات التشغيل والتجربة

### أولاً: تشغيل الموقع محلياً أو عبر الرابط المباشر
1. افتح رابط **Live Demo** في الأعلى، أو افتح ملف `index.html` في أي متصفح حديث.
2. جرّب تغيير خيارات البحث واضغط على زر **"♿ أدوات الوصول"** أسفل يسار الشاشة.

### ثانياً: تجربة المشروع كإضافة متصفح (Browser Extension)
1. افتح متصفح Google Chrome أو Microsoft Edge وانتقل إلى `chrome://extensions` (أو `edge://extensions`).
2. فعّل خيار **وضع المطور (Developer mode)** في الأعلى.
3. اضغط على **تحميل إضافة غير مضغوطة (Load unpacked)** واختر مجلد المشروع.
4. ستظهر أداة الوصول العائمة على أي موقع تزوره في المتصفح.
